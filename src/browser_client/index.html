What is SONAR Web?

SONAR Web introduces a modular framework for decentralized training of neural networks across Python, web, and mobile platforms. We develop and release a cross-platform open-source implementation with TensorFlow.js-based browser and Node.js clients, enabling real-time peer-to-peer model training without centralized infrastructure.

SONAR Web demonstrates practical, cross-platform decentralized training across real-world devices, benchmarking the viability of on-device collaborative learning in constrained and heterogeneous settings. It takes a step towards enabling decentralized learning over resource-constrained devices on the edge, contributing to a more inclusive, heterogeneous AI ecosystem.

🎯 Our Mission

Enable privacy-preserving, fully decentralized collaborative learning across heterogeneous environments—including mobile devices, web browsers, and Python-based clients with minimal setup and strict data locality.

System Design

SONAR Web is designed as a modular framework for real-time, privacy-preserving, and fully decentralized collaborative learning across heterogeneous environments.

Our system supports dynamic, on-the-fly participation from diverse clients with minimal setup and strict data locality, ensuring that your data never leaves your device while still enabling collaborative learning.

🔧 Core Components

  • Lightweight peer registration and discovery mechanism
  • Unified communication layer abstracting platform differences
  • Platform-agnostic configuration interface
  • Training and monitoring framework for collaborative learning
